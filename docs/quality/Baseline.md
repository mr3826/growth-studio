## 2. Root Cause Analysis: The Silent Export Defect

### 2.1 Acoustic Measurement of Baseline Exports
Running `ffmpeg -i ... -af volumedetect -f null -` on the baseline V0.01 release exports:

```text
Input: E:\GrowthStudio\exports\dukanbot-story-8-landscape.mp4
  Stream #0:1: Audio: aac (LC), 44100 Hz, stereo, fltp, 2 kb/s
  [Parsed_volumedetect_0] n_samples: 4114432
  [Parsed_volumedetect_0] mean_volume: -91.0 dB
  [Parsed_volumedetect_0] max_volume: -91.0 dB
```

The measured `mean_volume: -91.0 dB` and `max_volume: -91.0 dB` proves the audio stream is digital absolute silence, generated by `anullsrc`.

### 2.2 Mechanism of Failure
1. **Default Starter Configuration**:
   In `packages/contracts/src/index.js`, project generators (`createBlankProject`, `createSaasStarterProject`, `createGuidedStoryBanglaProject`) initialized `audio.muteAll: true` and `audio.musicAssetId: null`.
2. **Missing Multi-Track Mixer**:
   In `packages/render-adapter/src/index.js`, the rendering function accepted only a single `audioPath` (intended for music). There was no narration timeline, no scene-offset scheduling, no `adelay`/`amix` multi-track filtergraph, and no ducking.
3. **Misleading Validation Assertion**:
   The V0.01 test suite asserted `assert.equal(probe.audioCodec, 'aac')`. Because FFmpeg muxed `anullsrc` into an AAC stream, the test passed despite the output being 100% silent.
4. **UI Decoupling**:
   In `apps/web/src/components/`, audio was relegated to a simple file picker without playback sync, per-scene voiceover regeneration, or timeline waveform alignment.

## 3. Brand Identity Audit: EasyModerator vs DukanBot

1. **DukanBot Editorial Reference**:
   The V0.01 reference exports (`dukanbot-story-8`) utilized a cream (`#F9F9F6`), graphite (`#18181B`), and electric lime (`#CCFF00`) aesthetic based on a local reference analysis.
2. **EasyModerator Design System**:
   Per `Kinetic_Studio_Offline_Architecture_and_Input_Kit/easymoderator-promo-example.json` and specification requirements:
   - Primary: `#7460D9` (Violet)
   - Background: `#17223B` (Midnight Dark)
   - Text: `#FFFFFF` (Crisp White)
   - Accent: `#F4C35E` (Sunlight Gold / Amber)
   - Latin Font: `Inter`
   - Bangla Font: `Noto Sans Bengali` / `Nirmala UI`
   - Style Preset: `bold_future` (Bold & Future-Facing)
3. **Separation of Concerns**:
   Growth Studio must remain generic for any brand. EasyModerator will be a built-in, selectable brand preset and demo showcase. Switching templates must not overwrite user-customized brand colors.

## 4. Phase Architecture Plan (Waves A through E)

- **Wave A**: Fix silent exports, add explicit audio states (`silent`, `imported_voice`, `generated_voice`, `music_only`, `voice_and_music`), integrate local voice import (`.wav`, `.mp3`, `.m4a`), and enforce `volumedetect` assertions.
- **Wave B**: Integrate Gemini TTS via `CONTENT_STUDIO_GEMINI` (server-side only) with per-scene caching on `E:\GrowthStudio`, Bangla (`bn`) and English/mixed support, and graceful fallback to offline imported audio.
- **Wave C**: Build true FFmpeg multi-track audio pipeline (`atrim`, `adelay`, `amix`, `afade`, `aloop`, ducking, `loudnorm` target −16 LUFS), with browser preview audio sync.
- **Wave D**: Implement EasyModerator's Bold & Future-Facing brand preset and tokens across all 3 templates (`guided_product_story`, `bold_kinetic`, `app_showcase`), with true aspect ratio reflow (16:9, 9:16, 4:5).
- **Wave E**: Comprehensive negative tests, E2E browser verification, acoustic measurement matrix, and truth-in-release report.
